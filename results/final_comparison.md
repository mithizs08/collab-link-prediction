# Final model comparison (primary results)

_Generated by `scripts/final_comparison.py` from `results/final_comparison.csv` and `final_comparison_tests.csv`._

**Metrics.** Macro within-group scores (audit M2): positives and negatives/candidates are compared inside the established group (no author with ≤ 2 works before the cutoff) and the newcomer group separately, and the two scores are averaged. `hard_active` uses ROC-AUC; `rank_hard_active` uses query AUC (count-independent, because group matching changes candidate counts). **Values** for learned models are the mean over 5 seeds with a **seed-mean bootstrap 95% CI** (each resample applied to every seed, seeds' metrics averaged); sd = seed-to-seed sd. Deterministic models: ordinary bootstrap CI. **Tests** (primary): one paired bootstrap per comparison on the seed-averaged scores, 1,000 resamples, Holm-corrected across the 20-comparison family defined in `docs/decisions.md` (each split corrected separately).

Best GNN = gnn_pair_focused_sage_structural (highest validation macro hard_active ROC-AUC). node2vec = reported configuration (p = 2, q = 2, l1 operator, chosen on validation).

**Caveat (audit M1 / N3).** The saved GNNs were trained on Colab before the distance-2 fix: their pair-focused training positives include pairs at distance ≥ 3 while every negative is at distance 2. `gnn_pair_focused_sage_structural` learned that shortcut (shortcut check 0.775 ± 0.006: test ROC-AUC of far random negatives against distance-2 positives, `results/gnn_shortcut_check.csv`; above 0.5 = it ranks far non-collaborators above near collaborators; the retrained pair-focused LightGBM scores 0.011). The hybrid adds this GNN's out-of-fold score to the retrained pair-focused LightGBM, so it is built on a shortcut-trained model and is a secondary result. The GNNs were not retrained (no Colab rerun); `scripts/run_gnn.py` now trains distance-2 positives only.
