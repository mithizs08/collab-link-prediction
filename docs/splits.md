# Temporal splits

Built by `make splits` (`linkpred.data.splits`, summaries by `linkpred.data.splits_report`).
Decisions behind the design are in `docs/decisions.md`; leakage guarantees are enforced by
`tests/test_leakage.py`.

## Design

| split | input graph (works published) | predict first co-authorships in |
|---|---|---|
| train | 2015–2022 | 2023 |
| val | 2015–2023 | 2024 |
| test | 2015–2024 | 2025 |

- **Input graph:** all authors with a work before the cutoff (isolated authors included) and all
  co-authorship edges from ≤25-author works before the cutoff. Edge weight = number of joint works;
  `first_year` / `last_year` of the collaboration. Node attributes (`is_uts`, `n_works_before`,
  `degree`) are computed from the same pre-cutoff works only.
- **UTS author (per split):** at least one UTS-affiliated authorship in a work published before
  the cutoff.
- **Positives:** UTS–UTS pairs, both in the input graph, whose first joint work of *any* size is
  in the prediction year and who share a ≤25-author work that year.
- **Negatives (1:1 per type, saved separately):** UTS–UTS pairs of input-graph authors, unconnected
  in the input graph and with **no joint work of any size in the prediction year** (so no negative
  is a positive, or a hidden collaboration on a hyper-authored paper).
  - `neg_random`: uniform over all such pairs.
  - `neg_hard`: uniform over such pairs at shortest-path distance exactly 2 in the full input graph
    (the shared neighbour may be a non-UTS author).
- **Ranking candidates:** for each positive (u, v), 100 distinct (u, w): w a UTS author in the
  input graph, w ≠ u, unconnected to u, no joint work with u in the prediction year. u is the
  endpoint with the smaller author ID (an arbitrary but fixed choice).
- **Randomness:** one independent numpy stream per sampler per split, derived from `seed` in the
  config (`SeedSequence([seed, split_index]).spawn(3)`). Negatives are a fixed evaluation set; the
  five model seeds vary model training, not these files.

## Files (`data/processed/splits/<split>/`)

| file | contents |
|---|---|
| `nodes.parquet` | `node_idx, author_id, is_uts, n_works_before, degree` |
| `graph_edges.parquet` | `u_idx < v_idx, author_u, author_v, weight, first_year, last_year` |
| `adjacency.npz` | symmetric weighted scipy CSR, `scipy.sparse.load_npz` |
| `positives.parquet`, `neg_random.parquet` | `author_u < author_v, u_idx, v_idx` |
| `neg_hard.parquet` | same + `n_common` (common neighbours in the input graph) |
| `ranking.parquet` | `query_id` (row in positives), `head_idx, head, cand_idx, cand` |
| `meta.json` | all counts below, the seed, distance and cold-start diagnostics |

Node indices are per split; `author_id` is the stable key across splits.
`linkpred.data.splits.load_split(root, name)` loads everything for one split.

## What these numbers mean for evaluation

1. **Random negatives are easy for anything that looks at distance.** About 60–66% of positives
   are at distance 2 (they already share a co-author), while only about 1% of random negatives are,
   and about a quarter of random negatives are in a different component altogether. A model that
   only asks "do these two share a co-author?" will already separate most positives from random
   negatives, so high random-negative AUCs should be expected even from simple heuristics.
2. **Hard negatives remove that shortcut.** Every hard negative shares a co-author, so the model
   must rank pairs *within* the distance-2 shell (how many shared co-authors, how strong and how
   recent the ties, research overlap).
3. **But 34–41% of positives are not at distance 2.** Pairs at distance 3+, or disconnected, have
   no common neighbours, so neighbourhood heuristics give them a score of 0, below every hard
   negative. On hard negatives, these heuristics are therefore capped well below a perfect score
   by construction, and models that can reach beyond two hops (embeddings, GNNs, text) have
   room to do better. Results should be broken down by positive distance when they are compared.
4. **Cold start is common.** 30–38% of positives involve an author with fewer than 3 works before
   the cutoff (rising over time as UTS grows). These authors have little graph signal; this is a
   natural subgroup to report separately.
5. **Isolated endpoints are rare.** 12–27 positives per split include an author with no co-author
   before the cutoff; they are kept (they are in the input graph) and count as disconnected.
