# Data audit

**Source.** Existing OpenAlex snapshot from the earlier UTS project
(`uts-research-intelligence/data/raw/uts_works_2015_2025.json`, read-only), pulled with the
filter `institutions.id:I114017466` (University of Technology Sydney, ROR `03f0f6041`, verified
2026-10-14) for publication years 2015–2025. Built with `make data`
(`linkpred.data.build` then `linkpred.data.audit`). Notebook: `notebooks/01_data_audit.ipynb`.

**What the snapshot contains / lacks.** Per work: OpenAlex ID, publication_year, full
authorships with author IDs and institution IDs (incl. lineage), abstract_inverted_index. It does
**not** contain the `doi` field; DOIs are recovered from `primary_location` (id `doi:…` or a
`doi.org` landing page) for 96.7% of kept works. The OpenAlex list endpoint caps authorships at
100, which only affects works far above the 25-author cap. No re-pull was needed;
`linkpred.data.fetch_openalex` exists to rebuild from scratch.

Every number below is generated from the files in `report/data_audit/`.

## Interpretation and caveats

1. **Most new links involve a newcomer.** Only 9–15% of the pairs that co-author for the first
   time in a year (12–15% for cutoffs from 2020 on) have *both* authors already in the graph
   (`share_both_seen`, one-year windows). The task as defined
   (both authors seen before the cutoff) therefore covers a minority of new collaborations; this
   must be stated in the report, not hidden.
2. **External authors are only partially observed.** The snapshot contains only works with a UTS
   author, so non-UTS authors' collaboration histories are truncated to their UTS-linked papers.
   Even UTS authors' pre-UTS and non-UTS papers are missing. Structural features for external
   authors are biased downward. This argues for UTS–UTS pairs as the primary prediction target
   (see the open question in `docs/decisions.md`).
3. **Left-censoring.** The data start in 2015, so 2015–2016 "new" pairs include older
   collaborations, and early graphs are thin. Early years are poor label windows.
4. **Disambiguation.** 1,030 (name, UTS) groups map to more than one author ID (2,734 IDs). Some
   are genuinely different people with the same name; others are split profiles. Split profiles
   make a continuing collaboration look *new* (inflating positives) and split one author's degree.
   Several of the highest-degree hubs also carry the flag, so merged profiles are plausible too.
   Nothing is merged automatically.
5. **2025 completeness.** The snapshot was pulled in August 2026. 2025 works (6,311) are in line
   with 2022–2024, so the year looks complete, but late indexing could still add works; any
   missing 2025 links would make the 2025 window slightly harder for every model alike.
6. **Hyper-authored works** are rare (623 works, 1.0%; rising to 1.7% in 2025) but would have
   contributed at least 896k edge rows, almost as many as the 977k rows in the final edge table.
   Dropping them changes the graph a lot, which is the point of the cap.

## Open questions for review

- **Prediction target:** UTS–UTS pairs (primary) vs. all pairs with both authors seen. Both are
  tabulated under *Split candidates*.
- **Work types:** all types are kept (incl. errata, paratext, peer reviews, datasets). Errata
  usually repeat the original author set, so they add few new pairs, but excluding non-research
  types is a defensible alternative.
- **Split cutoffs:** recommendation in `docs/decisions.md`; not yet written to the config.
